# UX history

One file per round of UX suggestions made in the UI lab, at `<screen>/<yyyy-mm-dd>-<topic>.md`: the options shown,
which one was picked, why the others were turned down, what they faked, and how to bring one back from the round's
`ux/<screen>/<yyyy-mm-dd>` tag. Each screen's doc in [docs/screens/](../screens/README.md) links its rounds under
"Design history".

How rounds are made, closed and revived: the [ui-lab skill](../../.claude/skills/ui-lab/SKILL.md).
